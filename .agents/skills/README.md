# Habilidades de Agente (Skills)

- **Descubrimiento universal (Antigravity, OpenCode, Claude Code):** cualquier carpeta `.agents/skills/<skill_name>/SKILL.md` es auto-descubierta mediante **carga progresiva** (solo `name` y `description` al inicio; contenido y `references/` bajo demanda).
- **Skill activa del proyecto:** [`sdd`](./sdd/SKILL.md), que enlaza sus checklists de roles ([`roles_y_checklists_sdd.md`](./sdd/references/roles_y_checklists_sdd.md)) y runbooks de fases ([`runbooks_fases_sdd.md`](./sdd/references/runbooks_fases_sdd.md)).
